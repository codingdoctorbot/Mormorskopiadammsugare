First public release – *grandma's copy vacuum cleaner* sucks every photo and video out of your
backups of backups, keeps one of each, and sorts them into `Continent\Year\` folders.

**Download `Mormorskopiadammsugare.exe`** below (Windows 10/11, 64-bit, self-contained – no install).
Your original files are never changed, moved or deleted.

### What's in it
- **Extract:** finds photos and videos by content (also renamed, extension-less or recovered files),
  copies each unique one once, skips caches, thumbnails and junk. Interrupted runs simply continue.
- **Organize:** preview, then sort into `Continent\Year\` using capture dates, dates in file names,
  years in folder names, and GPS looked up offline. Optional country folders (`Europe\Italy\2015`) and,
  for photos from Sweden, county folders (`Europe\Sweden\Skåne län\2015`).
- **Best guesses inside the unknown folders:** photos without GPS get a probable place (`~Sweden`) from GPS
  photos taken within 3 hours, album folders are kept, and screenshots/graphics/downloads are set apart –
  still inside `_Unknown location`, clearly marked.
- **Stock photos and memes** (recognised by file name) get a `_Stock & memes` subfolder in each folder.
- Same name, different photo → both kept. Same photo, many names → one copy with the best name.

### Verify the download
SmartScreen may warn because the exe isn't code-signed. It was built by GitHub Actions from this
tag; check the signed build attestation and/or the checksum:

```powershell
gh attestation verify Mormorskopiadammsugare.exe --repo codingdoctorbot/Mormorskopiadammsugare
Get-FileHash Mormorskopiadammsugare.exe   # compare with SHA256SUMS.txt
```

### Known limitations
Exact duplicates only (resized/re-compressed copies are kept); MTS/MKV/WMV/MPG videos are dated by
names only; ZIP archives aren't opened. See the README for details.
